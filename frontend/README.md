# Volunteer HQ Frontend

React-приложение для управления волонтерами с дашбордами для администраторов и личными кабинетами для волонтеров.

## Функционал

### Для волонтеров:
- Регистрация и авторизация
- Личный кабинет с историей участий
- Просмотр предстоящих мероприятий
- Уведомления о новых мероприятиях

### Для координаторов/администраторов:
- Панель управления с KPI
- Список команды волонтеров
- Статистика по мероприятиям
- Календарь событий
- Пьедестал почёта лучших волонтеров
- Распределение по городам
- Мониторинг проблем

## Технологии

- React 18
- React Router DOM
- Axios для API
- Tailwind CSS для стилей
- Recharts для графиков
- Lucide React для иконок

## Запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите development server:
```bash
npm run dev
```

Приложение будет доступно на `http://localhost:5173`

## API

Приложение подключается к Django backend на `http://localhost:8000/api/v1/`

### Основные эндпоинты:
- `POST /api/v1/auth/token/` - авторизация
- `GET /api/v1/auth/me/` - текущий пользователь
- `GET /api/v1/events/` - мероприятия
- `GET /api/v1/my/participations/` - участия пользователя
- `GET /api/v1/dashboard/*` - данные для дашборда
